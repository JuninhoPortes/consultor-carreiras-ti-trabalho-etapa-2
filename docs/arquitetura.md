
# Arquitetura Inicial

## Objetivo
Desenvolver um sistema especialista baseado em regras para recomendar uma entre 10 carreiras em Tecnologia da Informação.

## Componentes previstos
- Base de conhecimento: perguntas, respostas e perfis profissionais.
- Motor de inferência: regras SE-ENTÃO utilizando Experta.
- Interface web: questionário e resultados utilizando Streamlit.
- Validação: testes com personas representando diferentes perfis.

## Organização
- `src/`: código-fonte e lógica do sistema.
- `docs/`: documentação e matriz de decisão.
- `tests/`: testes automatizados, a serem adicionados posteriormente.
